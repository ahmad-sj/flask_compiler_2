 0.  SETUP  -  run these two lines once per terminal session
===============================================================================

.\build.ps1
$CP = "out\classes;dependencies\antlr-4.13.2-complete.jar"

  build.ps1 regenerates the ANTLR parsers from grammars\*.g4 FIRST, then
  compiles. Never run javac alone: src\antlr\*.java is committed, so javac
  would just rebuild the stale copies and your grammar edit would do nothing.

  $CP is lost when you open a new terminal tab. Re-run that line.

 1.  RUN THE COMPILER
===============================================================================

# default: project\ -> output\ + compiler_output\
java -cp $CP app.FlaskCompiler

# quiet: write the artifact files but do not echo the trees
java -cp $CP app.FlaskCompiler --quiet-ast

# everything on the console: tokens + parse trees + ASTs + symbol tables
java -cp $CP app.FlaskCompiler --print-all

# just the token streams
java -cp $CP app.FlaskCompiler --print-tokens

# just the ANTLR parse trees (very long)
java -cp $CP app.FlaskCompiler --print-parse-tree

# explicit paths:  <input>  <outputDir>  <compilerOutputDir>
java -cp $CP app.FlaskCompiler project output compiler_output

# open the generated site
start output\index.html

  EXIT CODES:  0 = success   1 = compilation problem   2 = I/O failure
  Check with:  $LASTEXITCODE

 7.  VERIFY SPECIFIC BEHAVIOUR
===============================================================================

# --- is the output idempotent? (same input -> same bytes) -----------------
$a = Get-ChildItem output\*.html | Get-FileHash
java -cp $CP app.FlaskCompiler --quiet-ast > $null
$b = Get-ChildItem output\*.html | Get-FileHash
if ($null -eq (Compare-Object $a $b -Property Hash)) { "IDENTICAL" } else { "DIFFERS" }

# --- does every local link point at a file that exists? -------------------
foreach ($page in Get-ChildItem output\*.html) {
    $html = Get-Content $page.FullName -Raw
    foreach ($m in [regex]::Matches($html, '(?:href|src)="([^"]+)"')) {
        $t = $m.Groups[1].Value
        if ($t -match '^(https?:|//|#|mailto:|data:)') { continue }
        if (-not (Test-Path (Join-Path "output" $t))) { "DEAD: $($page.Name) -> $t" }
    }
}
"link check done"

# --- is the source in sync with the site? ---------------------------------
(Select-String project\app.py -Pattern '"id":\s*\d' | Measure-Object).Count   # products in source
(Get-ChildItem output\product_detail_?.html).Count                            # per-item pages
# these two numbers must match

 10. DEMONSTRATE THE KNOWN LIMITS  -  on purpose, in a scratch copy
===============================================================================

  Never do these in project\ - it is the graded input. Work on a copy.

Copy-Item -Recurse project out\demo

# --- {% include %} is outside the supported subset -------------------------
#   put  {% include "x.jinja" %}  in out\demo\templates\index.jinja, then:
java -cp $CP app.FlaskCompiler out\demo out\demo\site out\demo\co --quiet-ast
#   -> 18 token-recognition errors, one per character: J_STMNT_MODE has no
#      fallback identifier token, so an unknown tag name cannot be tokenised.

# --- a mismatched closing tag is silently repaired -------------------------
#   put  <div>x</p>  in a template, then rebuild:
#   -> accepted; the output says </div>, because the renderer re-emits the
#      START tag's name. RESULT: clean.

# --- values are not HTML-escaped ------------------------------------------
#   set a product name to  <b>BOLD</b>  in out\demo\app.py, rebuild:
Select-String out\demo\site\index.html -Pattern "<b>BOLD</b>"
#   -> emitted raw, in the body AND inside alt="...". |safe is not supported.

# --- two products with the same id ----------------------------------------
#   -> the file is written twice, the last one wins, silently.

Remove-Item -Recurse -Force out\demo

-------------------------------------------------------------------------------
 ERRORS YOU MAY CAUSE YOURSELF
-------------------------------------------------------------------------------

  "illegal character: '﻿'"
      You edited a .java file with PowerShell Set-Content -Encoding utf8,
      which writes a BOM that javac rejects. Edit Java in the IDE, or use:
      [System.IO.File]::WriteAllText($p, $text, (New-Object System.Text.UTF8Encoding $false))

  Exit code 255 with truncated output
      You piped a RUNNING java command into Select-Object -First N.
      PowerShell ends the pipeline early and kills the process, so it looks
      like the compiler crashed. Run the command, THEN search the files.

  My grammar change had no effect
      You ran javac instead of .\build.ps1, so the committed (stale) parser
      was recompiled. Always .\build.ps1 after touching a .g4 file.

  "Not built yet - run .\build.ps1 first"
      From check.ps1 / check-semantic.ps1 / verify-generation.ps1. Literal.

  $CP is empty / "Could not find or load main class"
      New terminal tab. Re-run the $CP line from section 0.

  "Cannot find path ...\output"
      You deleted output\ and did not regenerate. Run the compiler again.
